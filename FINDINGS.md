The missing index belongs in the base `store.Schema` DDL beside the `file_index` table declaration and other session lookup indexes. Using `CREATE INDEX IF NOT EXISTS` there makes `store.Rebuild` create it for fresh or rebuilt databases and makes `index.EnsureSchema` apply it to an already-current on-disk database when that schema is touched, so existing stores are backfilled without changing `pruneTombstonedIDs` or forcing a rebuild.
